## Domain 1 — Core Pipeline (`core/`, `pipeline.py`, `confidence_eval.py`, `config.py`, `utils/`)

**Summary.** Strong overall: bbox normalization is enforced at every boundary, PDF handles close in `finally`, LLM calls have consistent retry + circuit-breaker, async fan-out uses `TaskGroup`. Weaknesses cluster in whole-run memory buffering, never-closed `AsyncOpenAI` clients, and blocking model loads on the event loop. No DP-aligner or bbox-math correctness bug found.

### High

See priority item #13.

### Medium

- `core/workflows/stages/refine.py:97-105` — every refine-target page decoded simultaneously for the whole stage; a 500-page sparse run decodes hundreds of PIL pages at once. → Reuse the engine's 16-entry `_decoded_cache`.
- `core/ocr/processor.py:166` — fresh `AsyncOpenAI` (own httpx pool) constructed per request and **never closed** (`build_pipeline` at `plugins/ocr/pipeline_bridge.py:75` builds a new `OCRProcessor` per request). → Cache one client per `api_base` or add `aclose()` at teardown.
- `core/grounded/prompted.py:303` (`ensure_model_loaded`) — another throwaway unclosed `AsyncOpenAI` per grounded run. → Create once in `__init__`.
- `core/transcription/local_engine.py:66`, `core/ocr/trocr.py:87`, `core/translate/nllb.py:108` — first-use HF model loads run **on the event loop** (seconds-to-minutes stall for all requests). → `await asyncio.to_thread(_ensure_loaded)`.
- `core/ocr/resilience.py:220` — process-wide breaker registry shares one `asyncio.Lock` across event loops → `RuntimeError: bound to a different event loop` on any second loop (tests, Celery, embedded use); docstring at lines 191-193 is stale. → `threading.Lock` (critical sections are pure reads/writes).
- `core/pdf/embedder.py:554-563` (`embed_structured_text`) — output pass pre-rasterizes **all** pages into memory before serial page construction. → Interleave rasterize + build in bounded batches.
- `core/grounded/prompted.py:476-479` (`ocr_document` finally block) — cancelled tasks are never awaited ("Task was destroyed but it is pending"). → `await asyncio.gather(*tasks, return_exceptions=True)`.

### Low

- `core/workflows/stages/ocr.py:171-181` — one PIL page shared across concurrent crop threads (safe only by current non-mutation); document the invariant or lock.
- `core/workflows/stages/layout.py:47-55` — triple image decode per page; decode once, derive bytes from the buffer.
- `core/workflows/grounded.py:316-324` — O(repaired × blocks) identity scan; index by `id(block)` once.
- `core/lexicon/lancedb_store.py:676-710, 277-327` — fallback/listing paths load entire tables (incl. embeddings) into Python; push filters into the LanceDB query.
- `core/ocr/resilience.py:201-202`, `utils/security.py:30` — raw `os.getenv` bypasses validated `config.py` fields (audit-H3 convention).
- `core/translate/nllb.py:109` — deprecated `asyncio.get_event_loop()` in a coroutine; no guard against concurrent `generate` on the shared pipeline.
- **Doc drift:** AGENTS.md says `ALLOW_SSRF_LOCAL=true` is the code default; `config.py:124` defaults `False` (only the shipped `.env` sets true). → Align one or the other.

## Domain 2 — API & Security (`server.py`, `harness/`, `plugins/`, `utils/security.py`)

**Summary.** Token generation (256-bit, one-shot channels, constant-time compares on the progress/result paths), SSRF IP-pinning in the providers path, SQL parameterization, and the WebSocket cross-loop marshalling contract are genuinely solid. But the entire documented hardening layer is absent, and the job-status endpoint leaks result tokens. Within the local-single-user threat model this is acceptable; an operator following SECURITY.md to deployment profile 2/3 gets **zero** of the promised controls.

### High

See priority items #3, #4, #5, #6.

### Medium

- `plugins/ocr/plugin.py:455-461` (`_parse_upload`) — `await upload.read()` buffers the whole upload **before** the size check; default cap is 10 GB (`config.py:160-165`), and with no rate-limit middleware this is trivial memory DoS. Job/event bookkeeping sets (`plugin.py:214, 410-413`) are also unbounded. → Byte-budget streaming; expire bookkeeping in the TTL prune loop.
- `config.py:74-77, 308-324` + `harness/loader.py:100-118` — default cordis patch path lives in the **shared temp dir**; any local user can pre-plant `cordis.patch.yml`, and a patch row's `use:` executes arbitrary importable `module:attr` at boot. → Default the patch path into a mode-0700 dir; log patch pickup.
- `server.py:371-400` + `config.py:128-133` — the non-loopback-without-token refusal and placeholder rejection exist only in the CLI `main()`; `uvicorn omniscribe.server:app` (which DEPLOYMENT.md:180-183 recommends) bypasses both, and `auth_token` has no `min_length` constraint. → Move guards into `create_app()`/lifespan.

### Low

- `plugins/progress.py:279-282` (`cancel_channel`) — `POST /api/progress/cancel/{channel_id}` requires no session token.
- `plugins/ocr/plugin.py:577-580` (`clear_jobs`) — `DELETE /api/jobs` wipes all job history unauthenticated.
- `plugins/progress.py:284-291` — no Origin check on the WS handshake (CORS middleware doesn't cover websocket scope); the legacy `?token=` query branch contradicts the code's own comment.
- `plugins/providers.py:477-487` (`provider_models`) — `api_key` accepted as query param (see priority item #14).
- `plugins/state_backend.py:172, 382` — artifact token compared with `!=`, not `compare_digest` (SECURITY.md claims constant-time "on every bearer path"; practically unexploitable at 256-bit entropy).
- `server.py:182-187` + `plugins/ocr/plugin.py:520-521` — `ValueError` text echoed to clients.
- `plugins/state_backend.py:691-693` — SQLite DB and artifact blobs default into world-readable temp dir.
- `harness/loader.py:121-143` (`_apply_env_overrides`) — env overrides apply raw strings to any plugin field; document as trust-equivalent to editing cordis.yml.

## Verified-clean highlights

- **Pipeline:** bbox invariant chain end-to-end; `fitz` handle hygiene; TaskGroup fan-out with deliberate `OCRCancelled`/`CircuitOpenError` escapes; loop-safe shared httpx client; fail-open trust layer; atomic spellcheck dictionary compile.
- **Security:** parameterized SQL everywhere; 256-bit one-shot channel tokens with `compare_digest`; SSRF guard fail-closed with cloud-metadata ranges blocked even in local mode; TCP-pinning against DNS rebinding in the providers path; WS sends exclusively through the marshalled broadcast path; no path traversal in upload handling.
- **Frontend:** no XSS surface; strict analyzer; defensive JSON parsing; consistent Riverpod lifecycle (no setState-after-dispose); client/server route match on the OCR workstation path is exact.
- **Testing:** CI matrix matches C-3; real coverage gate in CI; no live network in fast tests; marker placement sound where used; conftest fixtures leak-free.
- **DevOps:** secret files ignored with zero commit history; `.dockerignore` correct; loopback-only port binds; digest-pinned redis; no PyPI publishing token in release.

## Recommended remediation order

1. **Wave 1 (unbreak the gates):** Dockerfile `USER`/apt order (#1); pyarrow importorskip (#7); Celery module refs (#2) or drop `--profile async` docs.
2. **Wave 2 (security):** status-endpoint token leak (#3); the two SSRF write-path gaps (#5, #6); SECURITY.md/.env.example reconciliation (#4).
3. **Wave 3 (correctness):** frontend fabricated fallbacks + dead routes (#10, #11); WS keep-alive (#12); async result fetch (Domain 3 Medium).
4. **Wave 4 (resource/perf):** `collect_batched_images` buffering (#13); `AsyncOpenAI` client lifecycle; event-loop model loads; refine/embedder batching.
5. **Wave 5 (hygiene):** docs drift table above; coverage gate in local addopts; low-severity items.
