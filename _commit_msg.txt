fix(audit-medium-d4): F4.7..F4.20 (Domain 4 cluster — Testing & QA)

Phase 5d closes 8 of 12 Domain 4 (Testing & QA) audit findings from
2026-08-17. 4 items reclassified as N/A positives (the audit's
"add @pytest.mark.slow" recommendation was contradicted by the
wall-clock evidence). 14 new regression tests in
`tests/test_audit_medium_d4.py` pin the post-fix behaviour.

F4.7/8 — test_pdf + test_text_layer_recall (N/A)
  * Verified via `pytest --durations=0`: the slowest test in
    `test_pdf.py` runs in 0.30s, the slowest in
    `test_text_layer_recall.py` runs in 0.03s. The audit's
    recommendation to add `@pytest.mark.slow` would be wrong.
  * Total file wall-clock: ~12.8s for 22 tests in `test_pdf.py`,
    ~7-9s for 31 tests in `test_text_layer_recall.py`. Both well
    within the fast-tier budget.
  * Regression test runs the actual `pytest --durations=0`
    invocation and pins a 1.0s per-test budget. If a test in
    either file ever crosses the budget, the test fails and
    the audit reasoning has to be revisited.

F4.9 — a11y testing gap (FIXED — documented)
  * AGENTS.md "Known Tech Debt" now records the gap: no
    `vitest-axe` / `@axe-core/playwright` in `package.json`, no
    Playwright a11y spec in `test.yml::e2e`. A button losing its
    accessible name silently lands without a regression test
    today; adding the test infrastructure is a separate track.

F4.10 — redundant @pytest.mark.asyncio decorators (FIXED)
  * Removed every redundant `@pytest.mark.asyncio` decorator
    in 6 active test files: `test_chunked_runner.py` (6),
    `test_processor_ab.py` (2), `test_transcription.py` (3),
    `test_ocr.py` (8), `test_phase1_async_streaming.py` (2),
    `test_live_llm.py` (11). `test_processor_ab.py` no longer
    imports `pytest` at all (its only use was the removed
    decorator). The auto-mode convention from pyproject.toml
    is now the single source of truth for asyncio.
  * Regression test scans every active test file for
    `@pytest.mark.asyncio`; a re-introduction (copy-paste from
    old code) fails CI immediately.

F4.11 — slow_dataset marker (FIXED)
  * AGENTS.md now documents the three-tier marker ladder:
    `slow` (Surya model load), `live_llm` (real VLM endpoint),
    `slow_dataset` (full OCR-Quality / KIE-HVQA fixtures, gated
    on the license review that lets `scripts/fetch_datasets.py`
    download the real data). Each marker has a one-line
    rationale and the matching `uv run pytest -m …` command.

F4.12 — synthetic_pdf fixture (FIXED)
  * `synthetic_pdf` in `test_chunked_runner.py` is now
    `scope="session"`. The 60-page PyMuPDF build is paid once
    per pytest run instead of once per test (~10 tests use
    the fixture; saves the per-test rebuild).
  * Backed by a new autouse `_session_tmp_path` helper that
    initialises a session-scoped temp dir via a `PathFactory`
    shim (pytest's built-in `tmp_path` is function-scoped, so
    a session-scoped fixture can't depend on it; renaming the
    parameter to `tmp_path` would also shadow pytest's built-in).
  * `PathFactory.get()` is the single accessor; reset at
    session start by the autouse helper.

F4.17 — Python matrix drift (FIXED — documented)
  * Inline comment on the matrix block in `test.yml` now

    so the matrix doesn't quadruple). A future reviewer who
    tries to "reconcile" the lanes has the answer in-tree.

F4.18 — test_response_schemas_and_reliability.py docstring (FIXED)

F4.19 — test_startup_validation_rejects_artifact_file (N/A)
  * The test writes a file at the artifact_dir path and
    expects `_validate_runtime_settings` to raise because
    the path is a file, not a directory. No `chmod`,
    `os.access`, or permission bits involved. The audit's
    "flakier than other tests" note was based on a misread
    of the source; the test is a structural
    directory-vs-file check, platform-independent on Unix
    + Windows.

F4.20 — fast-sync vs nightly-sync trade-off (FIXED — documented)
  * Inline comment on the `Sync deps (CLI + web extras)`
    step in `test.yml` now explains why the fast tier
    intentionally omits `--extra async-translation` (Celery
    + Redis + LangGraph): the async translation path is
    exercised in the nightly workflow where a real Redis
    container is available. A future contributor who tries
    to "fix" the fast sync by adding the async extra has
    the audit reasoning in-tree.
