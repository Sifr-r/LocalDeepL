Two complementary documents define a phased refactoring of LocalDeepL's monolithic modules:
- `docs/superpowers/plans/2026-07-13-god-module-decomposition.md` is an agentic worker checklist with checkbox tasks organized into four phases (P1–P4), each producing a self-contained PR that keeps tests green. P1 splits `core/ocr.py` into `core/ocr/{processor,prompts,filters,exceptions,__init__}.py`; P2 splits `core/grounded.py` into `core/grounded/{protocol,types,filters,parsers,rasterization,prompted,zai,__init__}.py`; P3 thins `api/routers/ocr.py` (~80 LOC) and extracts helpers into `api/services/{ocr_settings,ocr_pipeline_factory,ocr_response,ocr_jobs}.py`; P4 deletes the dead `api/routers/ai.py` and updates `ARCHITECTURE.md`.
- `docs/superpowers/specs/2026-07-13-god-module-decomposition-design.md` is the authoritative design doc: it declares hard constraints (public import surface preserved verbatim, behavior unchanged, no new features), defines module-level responsibilities and boundary rules per file, maps the request flow before/after, and lists acceptance criteria (no file > 350 LOC, smoke imports pass, full pytest + ruff + mypy clean).
- The `.mavis/plans/` directory is intended to hold scout-generated plans but is currently empty; these two files are the active artifacts.
