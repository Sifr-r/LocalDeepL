The suite is organized around a single `conftest.py` that provides session-scoped fixtures (`examples_dir`, `example_pdfs`, `surya_aligner`) and a reusable `_StubOCR` class to replace expensive external dependencies (Surya model loading, LM Studio calls). Individual `test_*.py` files each target a subsystem: document processing (`test_document*`), OCR resilience (`test_ocr*`), workflow engines (`test_workflows_*`), translation/evaluation (`test_translation_*`, `test_evaluation`), and end-to-end integration (`test_integration.py`). Ground-truth expectations live in `fixtures/ground_truth_*.json` files describing expected block layouts with bboxes and labels. Slow/integration tests are tagged with `pytest.mark.slow` so they can be skipped during quick iteration via `uv run pytest -m "not slow"`. Tests import production code via `local_deepl.*` after `sys.path.insert(0, ROOT)` in conftest, keeping the test package flat at the repository root alongside the source.
