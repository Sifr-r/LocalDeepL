Run all tests with `uv run pytest`; run only fast unit tests with `uv run pytest -m "not slow"`; run integration/slow tests explicitly with `uv run pytest -m slow`. Requires an `examples/` directory containing `digital.pdf`, `hybrid.pdf`, and `handwritten.pdf` or those tests will skip. The `TQDM_DISABLE=1` environment variable is set globally in conftest to suppress progress bars.
