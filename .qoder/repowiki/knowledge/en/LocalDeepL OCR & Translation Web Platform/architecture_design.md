The project is organized as a single Python package (`src/local_deepl`) with a clear layering: the `api/` routers expose FastAPI endpoints that delegate to thin service modules (`api/services/ocr_settings.py`, `ocr_pipeline_factory.py`, `ocr_response.py`, etc.), which in turn construct and run engines from `core/workflows/` (`HybridEngine`, `GroundedEngine`) through the `OCRPipeline` facade. Shared process-local state (text/metadata/export artifacts, job history, progress channels) lives in `api/routers/state.py` and is accessed uniformly by every router. Optional features (async translation, memory/RAG, preprocessing, TrOCR, NLLB) are gated behind `pyproject.toml` extras and imported lazily so the base install stays lightweight. The root `Makefile` and `uv` extras (`web`, `async-translation`, `memory`, `trocr`, `nllb`, `quality`, `comet`) provide unified entry points for setup, running the server, linting, typechecking, and testing across all children.
