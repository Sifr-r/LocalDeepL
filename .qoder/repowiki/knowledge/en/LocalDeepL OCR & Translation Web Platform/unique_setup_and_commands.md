`uv sync --extra web` installs the web server; add `--extra async-translation --extra memory` for background translation and glossary RAG. Run the server via `uv run local-deepl-server --port 8000`. Developer workflow: `make setup`, `make run`, `make test` (fast suite), `make lint`, `make typecheck`, `make doctor` (health check for Python/uv/Redis/model server). Windows users can use `install.ps1` / `install.bat` for one-click bootstrap and desktop shortcuts.
