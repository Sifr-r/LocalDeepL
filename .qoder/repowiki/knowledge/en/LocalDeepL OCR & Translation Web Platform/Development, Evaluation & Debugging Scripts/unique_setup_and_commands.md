Scripts are intended to be run via `uv run scripts/<name>.py [args]`. `dev.py doctor` checks that `uv`, Python ≥3.11, a reachable Redis instance (`REDIS_URL`), and an OpenAI-compatible model server (`LLM_API_BASE`/`LLM_API_KEY`) are available. `build_fixture.py` requires a running model server and writes fixtures to `tests/fixtures/`. `confidence_eval.py` expects those fixtures plus example PDFs under `examples/`. `ingest_lexicon.py` defaults to pulling TEI XMLs from the Alpheios `lan` repo GitHub API and stores embeddings in a local `chroma_db/` directory.
