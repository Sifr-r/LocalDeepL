- Single pytest package rooted at `tests/` with a flat layout: one `conftest.py` providing session-scoped fixtures (`examples_dir`, `example_pdfs`, `surya_aligner` — a real `HybridAligner` reused across the run to amortize ~5s Surya init) and per-test stubs (`_StubOCR`, `make_stub_ocr`).
- Tests are grouped by concern rather than by layer: `test_pipeline.py` / `test_workflows_hybrid.py` / `test_workflows_grounded.py` / `test_workflows_callback_decoupling.py` exercise the public `OCRPipeline` and the staged `HybridEngine` phases; `test_ai_router.py` / `test_api_safety.py` / `test_websocket_handler.py` cover the FastAPI surface; `test_evaluation.py` / `test_translation_evaluator.py` validate metrics against JSON ground-truth files in `fixtures/ground_truth_*.json`.
- Slow/integration tests (real PDF I/O + Surya detection) are isolated in `test_integration.py` and gated with `pytestmark = pytest.mark.slow`; the root `pyproject.toml` declares `slow` and `live_llm` markers under `[tool.pytest.ini_options]` with `asyncio_mode = "auto"` so async tests need no explicit event-loop setup.
- End-to-end assertions use PyMuPDF (`fitz`) to open both input and output PDFs and assert page count parity plus selectable text content; LLM calls are always replaced by inline `_Stub` subclasses of `OCRProcessor` that return marker strings verified in the output text layer.
- Repo-hygiene tests (`test_repo_hygiene.py`) parse `Dockerfile`, `compose.yaml`, `.pre-commit-config.yaml`, `.github/workflows/nightly.yml` and `pyproject.toml` via regex/YAML/tomllib to pin infrastructure invariants, keeping CI configuration from drifting out of sync.
