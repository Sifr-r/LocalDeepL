All scripts are intended to be invoked via `uv run scripts/<script>.py ...`; many depend on a local LLM server at `--api-base http://localhost:1234/v1` (or env `LLM_API_BASE`). Fixture generation requires either a running VLM endpoint (`build_fixture.py`) or a pre-existing sandwich PDF (`fixture_from_output.py`). Lexicon ingestion writes to a local `chroma_db/` directory and defaults to the `paraphrase-multilingual-MiniLM-L12-v2` embedding model.
