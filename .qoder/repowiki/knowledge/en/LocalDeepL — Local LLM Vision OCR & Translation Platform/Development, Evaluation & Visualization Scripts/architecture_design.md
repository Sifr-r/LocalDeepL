Flat collection of independent `argparse`-driven entry points under `scripts/`, each importing the local package via `sys.path.insert(0, ROOT)` so they can call into `local_deepl.core.*` (OCRProcessor, HybridAligner, PromptedGroundedOCR, OCRPipeline) without being installed. Two complementary fixture-builders exist — `build_fixture.py` runs a VLM backend to produce `(bbox,text)` blocks, while `fixture_from_output.py` reverse-engineers them from an already-produced 'sandwich' PDF using PyMuPDF (`fitz`) — both emit the same JSON schema consumed by `confidence_eval.py`. The evaluation script orchestrates both pipeline paths against every `examples/*.pdf` paired with a `tests/fixtures/ground_truth_*.json`, uses `local_deepl.evaluation.compute_report` for IoU/text-similarity scoring, and renders a Rich table. Debug/visualize scripts (`debug_alignment.py`, `visualize_bboxes.py`, `visualize_comparison.py`, `inspect_grounded_lines.py`, `inspect_pdf.py`, `debug_detection_only.py`, `debug_image_input.py`, `debug_llm_raw.py`) are one-shot tools that render PIL images or print intermediate structures; `ingest_lexicon.py` is a standalone RAG bootstrap that pulls TEI XML from GitHub and upserts entries into a local ChromaDB collection. There is no shared library inside this module — coupling is purely through the root `local_deepl` package.
