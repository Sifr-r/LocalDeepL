Flat collection of independent `argparse`-driven entry points under `scripts/`, each importing the project root via `sys.path.insert(0, ROOT)` to call into `omniscribe.core.*` (OCRProcessor, HybridAligner, PromptedGroundedOCR, OCRPipeline) without installation. Two complementary fixture builders share an identical JSON schema: `build_fixture.py` calls a VLM backend through `PromptedGroundedOCR` to produce `(bbox,text)` blocks, while `fixture_from_output.py` reverse-engineers them from an already-produced 'sandwich' PDF using PyMuPDF (`fitz`). `confidence_eval.py` orchestrates both pipeline paths against every `examples/*.pdf` paired with a `tests/fixtures/ground_truth_*.json`, uses `omniscribe.evaluation.compute_report` for IoU/text-similarity scoring, and renders a Rich table. Debug/visualization scripts (`debug_alignment.py`, `visualize_bboxes.py`, `visualize_comparison.py`, `inspect_grounded_lines.py`, `inspect_pdf.py`, `debug_detection_only.py`, `debug_image_input.py`, `debug_llm_raw.py`) are one-shot tools that render PIL images or print intermediate structures. `ingest_lexicon.py` is a standalone RAG bootstrap that pulls TEI XML from GitHub and upserts entries into a local ChromaDB collection. `dev.py` provides developer commands (`clean`, `doctor`) for environment health checks. There is no shared library inside this module — coupling is purely through the root `omniscribe` package.
