This root module defines the project's build, deployment, and developer workflow rather than application logic. `pyproject.toml` declares the Hatch-based Python package (`src/local_deepl`) with feature-scoped extras (`web`, `async-translation`, `memory`, `trocr`, `nllb`, `quality`, `comet`, `glossary`) and exposes the `local-deepl-server` CLI entry point. `Makefile` provides unified targets (`setup`, `run`, `test`, `lint`, `typecheck`, `doctor`) wrapping `uv run` commands. `Dockerfile` builds a multi-stage container with both `web` and `async-translation` extras baked in, running as a non-root `app` user on port 8000. `compose.yaml` orchestrates three services — `api` (FastAPI), `worker` (Celery, profile `async`), and `redis` — with health checks and environment-driven LLM endpoint configuration. `AGENTS.md` and `ARCHITECTURE.md` serve as the authoritative developer guide and architectural ledger documenting the core/ api/ decomposition, pipeline paths, extension points, and change history. `test_ui.py` is a headless Playwright smoke test against the running server. `.pre-commit-config.yaml` and `.fallowrc.json` configure pre-commit hooks and linting rules, while `.gitignore` excludes build artifacts and caches.
