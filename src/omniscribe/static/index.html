OmniScribe API server is running.

The interactive UI is the Flutter desktop client under client/, not this page. The in-browser workstation that earlier versions shipped was deprecated in 2026-08 (see the security model).

What's next?

  1. First time? Read the README and the troubleshooting guide — most first-run errors are documented.
  2. Run the Flutter client: cd client && flutter pub get && flutter run -d <platform>. Full instructions in client/README.md.
  3. Looking for a single binary? See RFC 001 — End-User Install Path. The PyInstaller bundle is on the v0.2 roadmap.

Operational probes

  • GET /api/health (alias /api/healthz) — liveness
  • GET /api/ready (alias /api/readyz) — readiness
